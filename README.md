# Guess My Number

A simple number guessing game that runs in the browser. The computer picks a number between 1 and 20, and you try to guess it.

## How it works

- Enter a guess and get a hint: too high or too low
- Every wrong guess lowers your score
- Your highscore is kept between rounds
- Hit "Again" to start over

## Built with

HTML, CSS, vanilla JavaScript

## Run it

Clone the repo and open `index.html` in your browser.
